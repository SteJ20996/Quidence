# AD01 · Visual Calculus · Beta 0.1

AD01 是 Quidence Dashboard 的第四個獨立模組。學生介面使用英文，對象是理解座標、函數圖形和直線斜率的初學者，提供單變數微積分的概念入門。

## 四節課

| 課題 | 可操作的圖形 | 重點區分 |
| --- | --- | --- |
| Limits | 對數距離滑桿、左右逼近、空心點與跳躍範例 | 極限與函數值；單側極限與雙側極限 |
| Derivatives | 移動第一點、縮小非零間距、割線與切線、可選的導數圖形 | 平均變化與瞬時變化；函數值與斜率；絕對值尖角處沒有導數 |
| Integrals | 左端點/中點/右端點矩形、2–64 個小矩形、改變右端點 | 近似與精確積分；有號累積與總幾何面積；位移與路程 |
| The connection | 原函數與累積函數同時顯示、移動終點、加入小區間 | 累積函數的值與斜率；連續條件下 A′(x) = f(x)；負終點的積分方向 |

每節課採用「一次預測 → 四個教學步驟與圖形探索 → 兩道新題 → 回饋」。各課可以直接選擇；預測允許選擇「不確定」。圖形控制項不會提交答案。新題使用不同的函數、參數或情境，圖形與說明均為本模組新編。

四節課的探索區域都提供播放、暫停和重播：觀察點逐漸靠近、割線逐漸接近切線、黎曼和矩形逐漸變窄，以及終點移動時累積圖形的變化。動畫可以隨時暫停；拖動控制項或離開目前的教學區域也會停止播放。瀏覽器設定為減少動態效果時，直接顯示終點狀態。積分範例保留正負貢獻的對照，導數範例的非零間距可以縮小到 0.001。

圖形和有限的數值展示用於幫助理解，教學文字保留代數理由、極限含義與連續性條件。首版不包括完整的 AP Calculus 課程、求導技巧庫、積分技巧、無窮級數或多變數微積分，也不宣稱已驗證教學效果。

## 檔案

- `dist/index.html`：靜態入口與共用的返回導覽。
- `dist/content.js`：四節課、12 次作答的定義和解釋。
- `dist/math.js`：確定的函數、原函數、割線、矩形和、總面積與累積計算。
- `dist/graphs.js`：原生 SVG 座標軸、曲線、圖形標記、文字描述。
- `dist/engine.js`：獨立工作階段、評分、草稿、不可變的答案歷史與儲存驗證。
- `dist/app.js`、`dist/style.css`：教學流程、圖形控制項、回饋和匯出。
- `tests/`：數學、工作階段、DOM fixture、入口連結，以及可選的真實瀏覽器檢查。

從整個儲存庫的根目錄執行 HTTP 服務，再開啟 `modules/ad01/dist/`。沒有新增打包流程、外部 CDN、帳號或雲端資料傳輸。

## 紀錄與操作

AD01 使用獨立的 localStorage 鍵 `ad01_beta01_session_v1`。重新整理後保留目前的答題階段、草稿、已儲存的作答和圖形設定；教學閱讀步驟從第一個步驟重新顯示，已開啟步驟的紀錄保留。答案修改後需要再次儲存才能繼續。原始預測與教學後的新題分別呈現；每次儲存的答案、先前的回饋與自述的外部協助都留在歷史中。

四節課全部完成後，可下載 JSON 答案歷史和 Markdown 總結，或列印總結。可選的文字解釋只會儲存，不自動評分。圖形操作或作答速度不會被解讀為努力程度、學習風格或是否使用 AI。無法使用儲存空間時，繼續使用分頁內的記憶體；無法讀取的既有紀錄保持原樣，可下載後明確選擇取代。其他模組的紀錄不受影響。

所有滑桿、選擇框與按鈕都使用原生 HTML 控制項，可以用鍵盤操作。圖形有標題、文字描述和外部數值讀數；圖形控制項更新時保留控制項本身。行動裝置採用單欄版面。不同類型的線和標記都搭配文字標籤使用。

## 檢查

不需安裝 npm 相依套件的檢查：

```sh
node scripts/test-ad01.cjs
node scripts/test-all.cjs
```

AD01 的 19 項檢查涵蓋極限與點值、尖角、割線代數、矩形估計、正負累積、積分方向、微積分基本定理、答案歷史、儲存與還原、損壞紀錄與四個 Dashboard 連結，並檢查四課動畫的完成、暫停與重播、控制項和導覽取消播放，以及減少動態效果的設定。DOM fixture 檢查會執行實際的應用程式碼，但不能取代瀏覽器算繪和無障礙驗收。

可選的真實瀏覽器檢查：安裝 Playwright 及其 Chromium 後執行 `node --test modules/ad01/tests/flow.browser.cjs`。如果 Chromium 在其他位置，可透過 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。`AD01_SCREENSHOT_DIR` 可指定截圖目錄。這個腳本涵蓋整個答題流程、圖形控制項、手機寬度、還原與下載。

本次開發通過一般的數學與狀態檢查，並對產生的 SVG 做了算繪檢查；目前的執行環境沒有 Chromium，因此尚未完成真實瀏覽器的視覺驗收。上線前需在 Mac/Windows 瀏覽器中開啟四節課，檢查圖形、鍵盤操作與手機版面。
