# AD01 · Visual Calculus · Beta 0.1

AD01 是 Cluevera Dashboard 的第四个独立模块。学生界面使用英文，面向理解坐标、函数图像和直线斜率的初学者，提供单变量微积分的概念入门。

## 四节课

| 课题 | 可操作的图像 | 重点区分 |
| --- | --- | --- |
| Limits | 对数距离滑块、左右靠近、空心点与跳跃例子 | 极限与函数值；单侧极限与双侧极限 |
| Derivatives | 移动第一点、缩小非零间距、割线与切线、可选导数图像 | 平均变化与瞬时变化；函数值与斜率；绝对值尖角处无导数 |
| Integrals | 左端点/中点/右端点矩形、2–64 个小矩形、改变右端点 | 近似与精确积分；有符号累积与总几何面积；位移与路程 |
| The connection | 原函数与累积函数同时显示、移动终点、添加小区间 | 累积函数的值与斜率；连续条件下 A′(x) = f(x)；负终点的积分方向 |

每节课采用「一次预测 → 四个教学步骤与图像探索 → 两道新题 → 反馈」。各课可以直接选择；预测允许选择“不确定”。图像控件不提交答案。新题使用不同函数、参数或情境，图像与说明均为本模块新编。

四节课的探索区域都提供播放、暂停和重播：观察点逐渐靠近、割线逐渐接近切线、黎曼和矩形逐渐变窄，以及终点移动时累积图像的变化。动画可以随时暂停；拖动控件或离开当前教学区域也会停止播放。浏览器设置为减少动态效果时，直接显示终点状态。积分例子保留正负贡献的对照，导数例子的非零间距可以缩小到 0.001。

图形和有限数值展示用于帮助理解，教学文字保留代数理由、极限含义与连续性条件。首版不包括完整 AP Calculus 课程、求导技巧库、积分技巧、无穷级数或多变量微积分，也不声称验证了教学效果。

## 文件

- `dist/index.html`：静态入口与公共返回导航。
- `dist/content.js`：四节课、12 次作答的定义和解释。
- `dist/math.js`：确定的函数、原函数、割线、矩形和、总面积与累积计算。
- `dist/graphs.js`：原生 SVG 坐标轴、曲线、图形标记、文字描述。
- `dist/engine.js`：独立会话、评分、草稿、不可变答案历史与保存校验。
- `dist/app.js`、`dist/style.css`：教学流程、图像控件、反馈和导出。
- `tests/`：数学、会话、DOM fixture、入口链接，以及可选的真实浏览器检查。

从整个仓库根目录运行 HTTP 服务，再打开 `modules/ad01/dist/`。没有新增打包流程、外部 CDN、账号或云端数据传输。

## 记录与操作

AD01 使用独立的 localStorage 键 `ad01_beta01_session_v1`。刷新后保留当前答题阶段、草稿、已保存的作答和图像设置；教学阅读步骤从第一个步骤重新显示，已打开步骤的记录保留。答案修改后需要再次保存才能继续。原始预测与教学后的新题分别呈现；每次保存的答案、此前反馈与自报外部帮助都留在历史中。

所有四节课完成后可下载 JSON 答案历史和 Markdown 总结，或打印总结。可选文字解释只保存，不自动评分。图像操作或作答速度不被解释为努力程度、学习风格或是否使用 AI。存储不可用时继续使用标签页内存；无法读取的已有记录保持原样，可下载后明确选择替换。其他模块的记录不受影响。

所有滑块、选择框与按钮使用原生 HTML 控件，可以用键盘操作。图像有标题、文字描述和外部数值读数；图像控件更新时保留控件本身。移动端采用单列排版。不同类型的线和标记与文字标签一起使用。

## 检查

无需安装 npm 依赖的检查：

```sh
node scripts/test-ad01.cjs
node scripts/test-all.cjs
```

AD01 的 19 项检查覆盖极限与点值、尖角、割线代数、矩形估计、正负累积、积分方向、微积分基本定理、答案历史、保存恢复、损坏记录与四个 Dashboard 链接，并检查四课动画完成、暂停与重播、控件和导航取消播放，以及减少动态效果设置。DOM fixture 检查运行实际应用代码，但不能替代浏览器渲染和无障碍验收。

可选真实浏览器检查：安装 Playwright 及其 Chromium 后运行 `node --test modules/ad01/tests/flow.browser.cjs`。如果 Chromium 在其他位置，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。`AD01_SCREENSHOT_DIR` 可指定截图目录。该脚本覆盖整个答题流程、图像控件、手机宽度、恢复与下载。

本次开发通过常规数学与状态检查，并对生成 SVG 进行了渲染检查；当前执行环境没有 Chromium，因此尚未完成真实浏览器视觉验收。上线前需在 Mac/Windows 浏览器中打开四节课并检查图像、键盘操作与手机排版。
