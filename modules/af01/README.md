# AF01 · Pre-calculus foundations · Beta 0.1

目前範圍：函數與定義域；圖形變換；單位圓與三角函數；指數與對數。學生介面為英文。四節課各包含一次初始判斷、四個教學步驟、兩道新題和回饋；課程共 12 次作答，另有獨立的 15 題入口基礎檢查。

答案或「不確定」都需要填寫理由。系統自動核對選項，理由保留給教師或 AI 導師閱讀，不會因為填了文字就自動給解釋分。回饋在兩道新題都儲存後顯示。報告分開呈現初始判斷、學後作答、修改歷史及自述的求助情形。

進度使用獨立的瀏覽器 key `af01_beta01_session_v1` 儲存。完整課程結束後可匯出 JSON 和 Markdown，並在共用的 Saved reports 中儲存副本。沒有雲端帳號或跨裝置自動同步。異常紀錄會保持原樣，只有學生確認取代後才重設本模組。

內容與題目為此次新寫的範例，圖形由公式與資料產生；沒有匯入外部題庫。這是入門試學與有限的證據收集，並非完整課程或經過驗證的能力測量。範圍與剩餘缺口見根目錄 `SUBJECT_EXPANSION_REVIEW.md`。

從專案根目錄啟動 `python3 -m http.server 8000 --bind 127.0.0.1`，開啟 `/modules/af01/dist/`。執行 `node scripts/test-new-subjects.cjs` 或 `node scripts/test-all.cjs`。數學、DOM 狀態、動畫、報告匯出、舊紀錄遷移與本機連結檢查已通過。SVG 已實際算繪檢查；目前環境沒有 Chromium，真實瀏覽器版面驗收尚未完成。
