# AF01 · Pre-calculus foundations · Beta 0.1

当前范围：函数与定义域；图像变换；单位圆与三角函数；指数与对数。学生界面为英文。四节课各包含一次初始判断、四个教学步骤、两道新题和反馈；课程共 12 次作答，另有独立 15 题入口基础检查。

答案或“不确定”都需要填写理由。自动核对选项，理由保留供教师或 AI 导师阅读，不因填了文字自动给解释分。反馈在两道新题都保存后显示。报告分开呈现初始判断、学后作答、修改历史及自报求助条件。

进度使用独立浏览器 key `af01_beta01_session_v1` 保存。完整课程结束后可导出 JSON 和 Markdown，并在共同 Saved reports 中保存副本。没有云端账号或跨设备自动同步。异常记录会保持原样，只有学生确认替换后才重置本模块。

内容与题目为此次新写的示例，图像由公式与数据生成；没有导入外部题库。这是入门试学与有限的证据收集，并非完整课程或经过验证的能力测量。范围与剩余缺口见根目录 `SUBJECT_EXPANSION_REVIEW.md`。

从项目根目录启动 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 `/modules/af01/dist/`。运行 `node scripts/test-new-subjects.cjs` 或 `node scripts/test-all.cjs`。数学、DOM 状态、动画、报告导出、旧记录迁移与本地链接检查已通过。SVG 已实际渲染检查；当前环境没有 Chromium，真实浏览器布局验收尚未完成。
