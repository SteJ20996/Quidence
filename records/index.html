Saved reports

Your records, on this device.

During public testing, accounts and cloud sync are paused. New answers, unfinished drafts, drawings, learning requests and saved reports are stored in this browser when saving is available. Quidence does not upload them for account sync or model training.

A different browser, device or website address will not automatically have these records. Private browsing and clearing site data can remove them. Local storage is not password-protected: people using the same browser profile may be able to read it.

Keep your work

  1. Use the same browser and site address to resume. Check any saving warning shown by an activity.
  2. Download a local-record backup before clearing browser data or changing devices. Confirm the file appears in Downloads and keep it privately.
  3. For a readable copy, open an activity report and download Markdown or open the separate printable report. Use its Print / save as PDF button.

A backup includes records stored by this browser, including older local workspace copies and unreadable records. It does not fetch earlier server records. It can contain private answers.

This reads the selected file on your device; it is not uploaded. Before confirmation, we check whether record groups are missing, identical, or different. Restore keeps identical records and adds missing ones. If any group differs, the entire restore stops; histories are not combined. Use a separate browser profile to view the backup safely, or download your current backup before clearing records if you want to replace them.

Delete browser records

  1. Download anything you want to keep.
  2. Click “Delete learning records from this browser” and confirm. This removes Quidence drafts, answers, saved reports, learning requests and local workspace backups from this site.
  3. Close other activity tabs. They will reload or block stale saving after the deletion. You can also remove this site’s data through your browser’s privacy settings if the button cannot finish.

Deleting browser records does not delete downloaded files, clipboard copies or records previously sent to a server or another service.

Before leaving a shared computer

Download privately only if you need a copy, then delete the browser records. Remove exported JSON, Markdown, HTML and PDF files from Downloads and empty the trash if appropriate. Clear clipboard copies and close report/activity tabs. Remove any previously saved browser passwords separately. A private browsing session can reduce local traces, but is not a guarantee that no copy remains.
