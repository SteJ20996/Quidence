# Quidence College Voice Lab

An English-only interaction and teaching demo for Linear Algebra and Statistics.

- Five stages: first idea, evidence, explanation with a scripted follow-up, transfer, reflection.
- Two exact mathematical models: horizontal vector stretching and normal confidence intervals with known population standard deviation.
- Recording and playback stay local to the open dialog. Audio is not uploaded or exported.
- Example transcripts are explicitly labelled and editable before confirmation. Existing text is appended to, never replaced.
- Follow-ups use a learner-selected reasoning focus or an unchanged authored example. Free prose is not semantically assessed, and no AI/provider API is called.
- Local drafts, submitted snapshots, raw/confirmed wording and earlier attempts are preserved separately. Unreadable or concurrently changed records are not overwritten.

Run npm test for mathematical, state and recorder lifecycle checks. Serve dist/ as a static site. No credentials or package installation are required.
