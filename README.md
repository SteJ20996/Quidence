# AA01 / AB01 — Private Development Workspace

这是一个私有开发仓库，用来保存教育网站代码、练习版本管理，并为以后整合多个模块做准备。

仓库名 `AA01` 是当前容器名称，不代表所有内容都已实现为 AA01 主系统。当前导入的是 AB01 线性代数 Beta 0.2 的独立源码快照。

这次导入不修改现有 AB01 在线网站，也不启用 GitHub Pages、不绑定域名、不增加学生账号或云端数据收集。

## 本地运行

在仓库根目录打开终端。若已安装 Python 3：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory modules/ab01/dist
```

打开 <http://127.0.0.1:8000>。结束时在终端按 Ctrl+C。Windows 安装了 Python Launcher 时，命令开头可改为 `py -3`。

若已安装 Node.js，在仓库根目录运行检查：

```sh
node scripts/test-ab01.cjs
```

测试脚本会自动进入 AB01 模块目录，避免从仓库根目录运行旧测试时出现路径错误。测试使用数学和 DOM fixtures，不能替代真实浏览器测试或学生学习效果验证。

## 开发约定

- 保留 `main` 的可运行版本；后续修改可放到独立练习分支。
- 每次提交写清楚改了什么，并检查相关流程。
- 真实学生记录、导出的作答、密码和 API 密钥放在代码仓库之外。
- Private 只控制源码访问；网页访问权限和研究数据要求需要另行处理。
- 未新增学生账号、统一学习记录或跨模块数据共享。
