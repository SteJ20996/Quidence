# Quidence：大量记录测试与数学地图方案

2026-10-09。代码基线为 GitHub main 对应的当前发布树；测试在独立本地浏览器及本地服务器运行，没有向正式网站发送压力流量。性能优化已在工作区完成；数学地图为交互预览，尚未接入正式主页。

## 测到了什么

测试数据由现有基础测试引擎生成：每次包含 15 道题、原始解释、提交历史、题目定义和派生报告。解释包含英语、西班牙语和中文，核对保存、重载和切换语言后原文不变。数据是合成样本，不能用来验证教学效果。

| 条件 | 结果 |
| --- | --- |
| 100 个并发本地 HTTP 请求，分 5 批，共 500 次 | 0 次失败；优化版 P95 158.4ms。只表示这次本地测试，不是 Cloudflare 的容量证明。 |
| 8 个独立浏览器上下文同时访问主页、诊断与报告 | 页面与保存成功；重载后各自记录独立。 |
| 10 / 100 / 250 次完整测试记录 | 历史完整；最后的未提交输入可以重载恢复。250 次档案约 296 万字符。 |
| 10 / 50 份完整报告 | 所有报告可访问；分页不会删除记录；新保存不会改变旧报告正文。50 份档案约 303 万字符。 |
| 100 份本次结构的报告 | 此浏览器的存储空间不足，无法植入这组数据。没有把这个条件算作通过。报告容量取决于实际文字、绘图与版本数量。 |
| 空间耗尽后保存新报告 | 明确报告失败；已有档案逐字不变。 |
| 同一活动在两个标签页中编辑 | 后一个过期标签页停止写入并提示冲突；第一个草稿保留，第二个标签页的草稿可单独下载。 |

## 找到并修复的瓶颈

原来每次键盘输入都同步序列化并重写整个答题档案。现在连续输入合并保存，停止输入约 150ms 后写入；失去焦点、提交、切换活动、隐藏页面及正常离开页面时同步保存。浏览器异常退出发生在这段短窗口内时，最后少量输入仍可能未落盘。此机制不能替代持久存储。

报告读取去掉了一次不必要的完整深拷贝；新增报告只迁移旧格式的指纹，不再重新计算所有当前指纹。是否增加版本仍比较真实记录，不能因指纹碰撞而跳过不同答案。日期格式器按语言复用。报告列表按最后保存时间排列，每页 20 条，所有历史版本仍保留；新增文字已有西班牙语翻译。

| 同样的本地条件 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 250 次记录，连续输入 100 个字符，正常 CPU | 5.53 秒 | 0.10 秒 |
| 250 次记录，连续输入 100 个字符，CPU 限速 4 倍 | 20.41 秒 | 0.30 秒 |
| 50 份报告，读取档案，CPU 限速 4 倍 | 86ms | 25ms |
| 50 份报告，保存新报告，CPU 限速 4 倍 | 304ms | 234ms |

时间包含测试工具的操作开销，会受机器状态影响；CPU 限速只是较慢设备的代理，不能代表真实 iPhone 或安卓手机。大档案初次恢复仍有可察觉的短暂停顿：250 次记录、限速 4 倍时重载约 615ms，观察到的最长主线程任务约 272ms。结果是降低卡顿，并非保证任何设备永不卡顿。

完整回归通过：npm test；28 项针对档案、原始证据、容量失败及语言的检查；浏览器 80 个活动页面 / 40 个草稿恢复流程；西班牙语 33 节课 / 132 个步骤 / 956 个控件状态。地图在 320、375、736px 检查了节点选择、语言切换、未来内容说明、Logo 加载和横向溢出，均通过。

可复现：设置可用的 `QUIDENCE_BROWSER_EXECUTABLE` 后运行 `npm run test:history:stress`。原始结果在同目录的 performance-baseline-20261009.json 与 performance-optimized-20261009.json。

## 数学地图怎么放

建议主页保留当前直接选课功能，在课程选择附近加入一个简版路线和“Explore the mathematics map”入口；完整地图使用单独页面。地图先帮助学生看懂知识关系，点击节点后再显示这部分学什么、与哪些内容相连，以及现有课程、测试和项目的入口。移动端改成纵向排列，避免缩小一张桌面大图。

地图使用“建立基础 → 连接思想 → 应用方向”三个区域。预代数、代数 I、代数 II、预微积分、微积分构成常见路线；几何与代数互相支持，统计及线性代数保留并行分支。物理链接目前的两门基础课程；经济学与更高阶数学显示为未来探索，不能让学生误以为已经有完整课程。地图展示相关概念的联系，而不是唯一的学习顺序或课程解锁条件。

设计参考现有课程目录，以及 [Common Core 的函数与建模说明](https://www.thecorestandards.org/Math/Content/HSF/) 和 [Illustrative Mathematics 的代数 I 路线](https://tasks.illustrativemathematics.org/blueprints/A1)。节点、文字、图形和产品布局为本项目方案，没有复制第三方课程材料。

目前预览只显示选择状态，不虚构学生等级或掌握率。正式接入后可先显示可核对的事实，例如“打开过”“提交过答案”“有待复查的具体题目”。后续再根据多次表现和人工复核，为某个错误模式提供下一步建议；代数困难时可推荐有关的几何表示，保留所依据的题目和教学变化。

## 后续优先级

1. 在真实手机上复测当前版本，尤其是报告打开、键盘输入、绘图及后台恢复。
2. 长期学习记录迁移到按活动分开的 IndexedDB 存储，配置可见的容量提示、备份与原有档案迁移。当前 localStorage 的空间限制已经被实际测到；不应靠删除旧学习证据来解决。
3. 经确认后接入数学地图及课程入口；再接入有证据的学习记录状态。
4. 增加实际页面性能与错误观测，用真实慢操作和失败率判断何时需要进一步优化。上线容量需要独立、有限度的环境测试；访问统计中的累计请求数不能替代并发或性能测量。

当前静态资源由 Cloudflare 分发。其[静态资源计费与限制文档](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)说明静态资源请求免费且数量不限；这不代表前端计算、浏览器存储或未来数据库及 AI 接口也没有瓶颈。
