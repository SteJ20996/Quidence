# Site-wide appearance review — 2026-10-14

Quidence now offers three appearance choices on all 24 published HTML entry points:
Paper (warm paper and soft edges), Atlas (editorial serif headings and fine rules),
and Studio (pastel geometric accents and large rounded surfaces). Paper is the default.
The existing map, subject blocks, lessons, diagnostics, projects and saved-record flows
remain available in each theme. Qidolab is a separate website and keeps its own branding.

## Persistence and accessibility

- A synchronous, versioned head script restores the validated `quidence_ui_theme_v1`
  preference before styles load. It is independent of locale and learning-record keys.
- The three native buttons have visible names, selected state, keyboard focus and
  a minimum 44 px height. English and Spanish labels follow successful locale changes.
- Theme changes apply immediately without reloading the activity. Other tabs receive
  the same preference through the browser storage event.
- Unavailable browser storage does not block the controls; an explicit message says
  the preference applies only to the current visit. Invalid values fall back to Paper.
- Portable reports embed the selected presentation without network dependencies;
  print output uses white paper and excludes theme controls.

## Validation

- The local source snapshot matched GitHub main `2ddba15` before editing.
- All 24 public pages include one early initializer and one versioned theme stylesheet.
- Browser theme checks cover 144 page layouts: 3 themes × 24 pages × desktop English
  and 320 px Spanish. No horizontal overflow, clipped theme buttons, script errors,
  or HTTP failures were found.
- The existing brand suite covers 192 layouts, both languages and 4 widths, including
  logo contrast, header overlap and offline report branding.
- Existing home checks cover 12 layouts and 36 map states; retained exact draft text
  and saved reports through repeated navigation and language changes.
- Preference checks cover reload, a restored browser session, a new tab, live tab
  synchronization, keyboard selection, language changes, unavailable storage and
  unchanged non-theme storage. Standalone reports retain original answer text.
- Rendered desktop, mobile, course, foundation and report screenshots were inspected.
  Residual homepage background and header overrides were corrected after inspection.
- Unit suites, static release build, link validation, cache versions and whitespace
  checks pass. CI also runs the new theme browser suite alongside existing activity,
  localization, mathematics and record-preservation checks.

Browser persistence belongs to the same browser profile and site origin. Clearing
site data resets the choice. Theme preferences are not synchronized through accounts.
